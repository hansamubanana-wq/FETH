# Codex実装指示書: レース場のグラフィックをリアルに（v0.16.0）

## 要望

「image 2.0（GPT Image 2）を使って、レース場などグラフィックをリアルにしてほしい」

## 分析（実装前に必読）

現在の3Dシーン（src/race3d.js）は、地面・ダート・観客席・掲示板など**すべて手続き的な
CanvasTexture**（単色＋ノイズ＋ストライプ）で作られている。形状はthree.jsのジオメトリなので、
リアルさが出ない主因は**テクスチャの質**であって形状ではない。

したがってリアル化の本筋は、**image 2.0で高品質なテクスチャ／背景画像を生成し、
既存のCanvasTextureを差し替えること**。形状の作り直しは最小限でよい。

## 生成するアセット（image 2.0 / GPT Image 2 で作る）

`assets/art/tex/` に配置。**シームレスにタイル可能**なことを最優先（継ぎ目が出ると一気に安っぽくなる）。

1. `turf.png` — 芝の真上からのクローズアップ。**シームレスタイル**、1024px以上。
   刈り込みのストライプは入れない（ストライプはシェーダ／繰り返し側で表現するため、
   ここは均一な芝の質感のみ）。緑が単調にならないよう自然な色ムラを含める
2. `dirt.png` — ダートコースの砂。**シームレスタイル**、1024px以上。蹄跡・砂粒感のある茶褐色
3. `crowd.png` — 観客席スタンドを正面から見た画像。横方向にタイル可能。
   人が密集した客席（顔の描写は不要・粗い色の集合でよい）。夜間照明でも昼でも使える中間的な明るさ
4. `sky-day.png` — 昼の空（雲つき）。**エクイレクタングラー（360度パノラマ、2:1比率）**が望ましい。
   three.jsの `scene.background` に EquirectangularReflectionMapping で使う
5. `sky-evening.png` — 夕方版。同じくパノラマ2:1
6. `sky-night.png` — ナイター（星空＋わずかな街明かり）。同じくパノラマ2:1

※パノラマ生成が難しい場合は、既存のグラデーション空を残し、雲だけ高品質なアルファ付き
　スプライトに差し替える方針でもよい。**破綻するなら無理にパノラマにしない**こと。

## 実装

- `_createGrassTexture` / `_createDirtTexture` を、生成画像の `TextureLoader` 読み込みに差し替える。
  `wrapS/wrapT = RepeatWrapping`、`repeat` は現状の見た目のスケール感を保つ値に調整、
  `colorSpace = SRGBColorSpace`、`anisotropy` は `renderer.capabilities.getMaxAnisotropy()` を使用
- **読み込み失敗時は現在の手続きテクスチャにフォールバック**すること（オフライン・404でも
  レースが成立すること。既存の2Dフォールバック思想と同じ）
- 芝の刈り込みストライプは、テクスチャに焼き込まず、**別レイヤー or 頂点カラー/第2マテリアル**で
  薄く重ねる。現在の縞表現の雰囲気は残す
- 空は天候システム（昼／夕方／ナイター）と連動させる。既存の天候切り替えロジックを流用
- 観客席テクスチャを既存の観客メッシュに適用（現在の色ノイズより自然に見えるように）
- ライティングは新テクスチャに合わせて微調整可（過度に暗く／白飛びしないこと）

## 制約（毎回同じ・必読）

- ビルドなし静的サイト維持、Vanilla JS + three.js (importmap)
- **動的カメラの「全馬が常に画面内」ロジックには手を入れない**
- **レースバランス（着差・勝率分布）とレース所要時間は変えない**
- 2Dフォールバック（src/race.js）を壊さない
- **パフォーマンス最優先の注意**: テクスチャ追加でモバイルのメモリ・帯域が増える。
  各テクスチャは**適切に圧縮**し（1枚あたり目安 300KB 以下、合計2MB以内）、
  巨大PNGを貼らないこと。必要ならリサイズ・減色する。
  既存のFPS動的フォールバック（qualityLevel）と共存させること
- 完了時 `src/version.js` を APP_VERSION 0.16.0 / APP_BUILD 21 に、index.htmlのバッジも更新
- タスクごとに日本語メッセージで独立コミット。push・デプロイはしない
